智语外呼 · 蓝色桌面前端

启动
1. Windows 双击本文件夹内“打开网页.cmd”。需要已有 Python，无需 Node、npm 或构建。
   启动器仅绑定 127.0.0.1，使用 8080—8090 中可用端口；已运行本页面时复用。
2. 也可在项目目录执行：
   python -m http.server 8080 --bind 127.0.0.1 --directory web
   浏览器打开 http://127.0.0.1:8080 。此方式按 Ctrl+C 停止服务。
3. 不要直接以 file:// 打开 index.html，浏览器会限制 ES modules。
4. 网页文件应连同 assets 文件夹一起保留。所有资源在本地，不依赖 CDN。

本次实现
首页只显示桌面场景与操作入口，下方不再排列工作台、报告或介绍。
采用真正独立的 HTML 文档：index.html、workbench.html、report.html、about.html、guide.html。
工作台、项目介绍、会话报告各有自己的内容和布局，通过原生链接跳转；不是同一页面隐藏区块或锚点滚动。
点击物件进入对应功能页，每页可返回桌面，支持浏览器前进、后退、刷新和直接打开文件地址。
离开工作台会暂停模拟；返回后手动继续。首页机器人和“开始模拟演示”属于明确的播放操作，可以开始或继续模拟。
仅合成记录临时写入本标签页 sessionStorage，使不同文档可读取同一份模拟结果；刷新保留，可在报告页清除。
这是浏览器临时存储，不是业务后台登记。不使用 localStorage，不保存音频、真实商家信息或密钥。
浏览器禁止临时存储时会提示跨页无法保留记录，工作台仍可播放并直接导出日志。
原 #/workbench 等旧链接会跳转到对应 HTML 文档，兼容旧书签。
首页使用用户确认的蓝色书房场景：左窗、右上悬臂灯、局部桌布和放大的物件。
物件保留白色、金银色、蓝色涂装等自身材质颜色；蓝色主要用于环境。
名称和操作提示默认常驻，可隐藏；鼠标悬停或键盘聚焦仍显示。
手机和平板将同名操作入口排在场景下方，避免挤在小图上。

九个物件的操作
小语机器人：打开模拟工作台并播放当前合成场景；已有暂停记录时继续，没有暂停记录时开始新一轮模拟。
审核依据：展开合成商家申请与规则说明，不触发真实业务查询。
录音机：打开当前模拟会话报告；无数据时明确提示尚未运行。
陀螺：依次切换正常补正、身份不符、工具失败；有暂停会话时锁定，先继续或结束再切换。
台灯：在明亮与柔和画面间切换，仅改变场景明暗，不改变色相。
案例册：进入案例选择。
项目手记：跳转到项目介绍和当前能力边界页面。
钢笔：有模拟事件后导出 JSON，包含 simulated:true；未运行时提示先演示。
便笺：跳转到操作指南页面。

模拟与真实能力的边界
这是场景插画与语义 HTML 按钮结合的二维交互页面，不是可旋转的三维模型。
暂不支持机器人三维拖拽、陀螺实体旋转、录音机音频播放。台灯调整画面亮度，不进行物理光照计算。
三种合成流程在浏览器运行：逐条字幕、流程进度、模拟工具调用、结构化结果、暂停继续、停止及重播。
报告页只读取当前标签页的合成快照，不在后台继续计时或自动完成流程；不伪造跨页后的成功状态。
工具回写超时会保持 persistence_status=unknown、outcome=null、record_id=null，不宣称登记成功。
身份不符时客服停止披露申请详情。所有业务规则与案例都为合成数据，不代表官方政策。
不访问业务 API、不申请麦克风权限、不采集或播放音频、不保存密钥。
真实通话及麦克风按钮禁用，ASR/TTS/业务服务状态明确为未配置或未接入。
计时是模拟播放经过时间，不是实测语音时延；P50/P95 保持未测量，质检仅检查模拟分支。
adapter.js 预留受控后端代理边界；BreezeBlue/本地 TTS 尚未接入。
API-CONTRACT.txt 是待联调草案，不代表已经存在的后端接口。
