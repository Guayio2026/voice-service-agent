# Grounding：合成业务依据管理

规则目录：data/synthetic/rules.json。内容来自项目既有合成案例，不是官方资料。字段含编号、版本、来源说明、生效起止日期、状态、问题和处理方式。未设置结束日期表示该模拟规则无指定结束日期，不表示官方永久有效。

每次查询后，逐项核对应用版本、规则有效期（上海日期）、状态与问题/处理方式是否精确一致。缺失、重复编号、损坏文件均失败关闭；冲突内容不原样播报。有效资料也不证明用户实际已提交或审核已通过。

回答返回 grounding.checks 与 grounding.citations；页面提供可展开的回答依据，持久化 trace 留存同样信息。citations 仅列出本次材料解释实际使用的规则。截止时间、费用、入口仍无依据，不补造。

待登记内容绑定规则目录摘要；目录更新或引用规则过期后，旧确认失效。完成登记的后端再次检查依据；TTS前检查旧回答的依据是否仍有效。非完成类登记如人工核实申请仍可按原确认流程处理。

检索分数仅辅助意图识别，不当作答案正确概率。本实现限定于结构化合成业务，并非任意自由文本的自动事实核查。正式资料到位后需审核来源、规则及业务接口，再扩展正式资料接入；不能把 synthetic 改成 false 就当作正式上线。

验证：test_grounding.py 包含有效引用、缺失、损坏、重复、过期、未生效、停用、版本差异、内容冲突、旧确认失效及缺失依据不播报补正动作。
