2026-11-08: overlapping voice pipeline follow-up

Measurement: scripts/benchmark_voice_e2e.py injects recorded speech through
WebAudio into the real browser capture, VAD, ASR, business, TTS and playback
pipeline. Start is the end of the last input 20ms block with RMS > .002.
End is scheduled first output plus AudioContext.outputLatency estimate.
This is software E2E, not a physical microphone/speaker measurement.
Greeting/connection warm-up occurs before the recorded question. Not cold start.

Changes:
- Read-only speculative inference uses cancellable async HTTP. A completed
  revised question can supersede obsolete work instead of waiting for it.
- Equivalent punctuation-only read-only ASR revisions retain in-flight work.
- A cancelled optional prediction falls back to actual classification instead
  of propagating cancellation into the real turn. Actual turn cancellation
  still propagates. Regression test covers this race.
- Limited whole-utterance grammar routes clear informational topics locally;
  mixed actions/unknown wording still use the model. No permission is granted.
- Conservative pause handling for retractions avoids treating a comma as the
  end of the entire question. ASR instability remains a source of variance.
- Breeze idle socket monitoring detects peer closure before reuse.
- Existing validated-first-sentence TTS overlaps subsequent LLM generation.
