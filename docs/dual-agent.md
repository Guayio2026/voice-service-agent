# 双Agent第一版
前台仍用现有DS Flash非思考分类。后台每轮回复后异步预测最多3个后续问题，仅检索公开合成知识，无业务工具。前台不等待后台；精确问题命中缓存，否则回退原检索。不是语义向量缓存，也不承诺命中率或端到端提速。
缓存独立于各会话，120秒有效，最多12项；知识文件摘要变化失效；打断/身份更新清除缓存并取消后台任务。每会话最多8次后台预测，每次150输出token上限、8秒逻辑超时，无自动重试。取消无法保证供应商同步请求立即停止，可能继续计费。
业务依据仍实时Grounding，业务权限不由预测结果决定。后台共用现有模型配置，未切换小模型。
播报中96ms持续高概率人声触发停播，保留非播报192ms门槛。这是算法门槛而非实测延迟；需检验外放回声误触发。
