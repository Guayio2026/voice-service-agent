Three overlapping voice stages — 2026-11-08

1. Partial ASR text now schedules read-only preparation after 250 ms without
   revision. Revised text replaces pending preparation. Agent speculation uses
   exact generation/context/text matching before final reuse; it cannot call
   business tools. Identity, pending operations and paid-work limits still apply.
   A final transcript need not reuse an earlier prediction if the input changed.

2. Complex verified explanatory turns opt into application/x-ndjson from
   /api/speech via stream_reply=true. Short exact-rule answers keep their existing
   faster path. Identity and business operations still finish before any speech.
   The first complete substantive sentence comes directly from the validated
   business answer. It is labelled verified_business_answer in the stream.
   An additional nonthinking LLM call generates the remaining oral explanation
   concurrently. This is a hybrid first-answer + generative-continuation design,
   not a claim that the first sentence itself came from newly streamed tokens.
   Complete generated sentences pass the existing guard and, for paraphrases,
   an additional semantic support check before synthesis. Exact whole source
   sentences reuse source validation. Semantic checking is model-based, not a
   mathematical factuality guarantee. Extra generation/checks consume API usage.
   Separate tasks generate text, check sentences, send text.append/text.flush,
   and receive Breeze PCM. turn.end is sent only once text input ends.
   SSE consumption never waits for the sentence checker (total text is bounded),
   so model completion timing is not inflated by a full sentence queue.
   The UI displays the streamed oral text separately from expandable source facts.
   Logs label generated text as generated, not confirmed heard by the user.

3. Continuous microphone capture/VAD remains active during generation/playback.
   Human speech stops browser playback locally, cancels model/verification/TTS
   work, and retains pre-roll for ASR. Cancellation clears old audio; Breeze
   socket reuse requires its matching cancellation acknowledgement. Click mode
   and the manual stop button remain supported.
