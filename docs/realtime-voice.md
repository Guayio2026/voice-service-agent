当前入口：点击开始测试通话默认启动持续监听，麦克风和VAD准备完成后才播报开场，第一句可插话。取消自动连续对话勾选项；启动监听失败时不播报开场，显示错误供重试。停止后释放麦克风，仍可使用点击说话。下方早期可选模式说明已被本段取代。

新增入口：工作台提供默认不勾选的“通话开始后自动连续对话”。勾选后点击“开始测试通话”，先开启麦克风与人声检测，再播报开场；未勾选保留逐轮点击说话。也可在已有会话中点击“开启连续对话”。停止后释放麦克风并恢复点击模式。

# 连续对话与实时插话

创建测试会话、模拟确认身份后，点击工作台的“开启连续对话”。等待持续监听提示后直接说话，停顿约 0.9 秒提交；AI 思考或播报期间可以再次开口。点击“停止 / 打断”或切换至流程演示会关闭麦克风。原有“开始说话”仍是手动单轮模式。

浏览器持续运行回声消除、RNNoise 降噪和 Silero 人声检测。连续高置信度人声约 192 ms 后触发插话，立即清空排队音频、终止浏览器回复请求，并通知后端取消当前业务图任务。保留约 600 ms 开头音频，在 ASR 连接成功后补发；等待服务端取消确认后才提交新一句文字。无语音时不向 ASR 上传音频。模型加载、识别连接或音频队列异常会停止监听并显示错误。

后端使用 generation 拒绝旧轮次的晚到请求。取消业务图不等于撤销已完成的业务写入；已经发往供应商的同步模型请求可能继续执行、产生费用，但其迟到结果不会再进入已取消的业务图。插话会清除待确认内容，之后需要重新确认。

建议佩戴耳机。浏览器回声消除取决于设备及系统，不能保证外放环境完全不误触发；旁人的说话也可能触发插话。192 ms 是检测阈值，不是实测 P50/P95。应另外用真实设备、外放和耳机、长短插话及背景噪声测量误打断率和端到端时延。

验证：`tests/test_voice.py` 覆盖服务端取消、锁释放、旧请求拒绝及新轮次；`tests/check_barge_in_browser.py` 使用模拟音频、模拟 ASR 和模拟接口，在 Edge 中验证预录缓冲、自动停播、连续下一轮、停止与切页释放麦克风，不调用付费服务。

身份对话修复：未核验时允许问名字、问候、感谢的受控回复；明确自述“是该商家的负责人”等可以进入模拟身份确认。否定表达与不确定、转述、混合表达不会授予身份。未理解时简短询问，不重复开场。新增test_identity_smalltalk.py回归。

模拟阶段自然理解：固定短语未匹配时，调用模型输出受限的yes/no/identity/purpose/decline/unclear标签，8秒超时。标签仅驱动合成演示身份分支；不提供申请资料给该分类器，不接受工具参数，不授予正式身份。模型失败或标签非法时继续澄清。身份分类准确率仍需真实模型样本评估；离线测试验证控制流程而非模型准确率。
