Vue 前端迁移（2026-11-07）

页面入口：web/vue/main.js。
页面组件：web/vue/index.js、workbench.js、report.js、about.js、guide.js、mock.js。
工作台样式：web/vue/workbench.css。

采用 Vue 3.5.13 本地浏览器构建，无需 npm、CDN 或额外开发服务器。
启动方式仍为 scripts/start-voice.ps1，打开 /workbench.html。
页面组件负责模板；工作台模式使用 ref 和 Vue 点击事件管理。
现有 voice.js、workbench.js、home.js 等在 Vue 挂载后加载，作为兼容控制层。
这是一阶段迁移：音频和业务交互仍有直接 DOM 操作，并未全部改成 Vue 响应式状态。
组件模板目前是 JS 字符串，不是 .vue 单文件组件；不需要编译。
后端接口、案例文件、麦克风 worklet 及音频模型保持原实现。
旧 HTML 备份位于 runtime/vue-backup。不要重新运行迁移脚本来覆盖后续组件编辑。

验证：python web/qa/verify_voice.py；python web/qa/verify_vue.py。
测试使用模拟接口，不产生云端语音或模型费用；真实云端录音对话未在本次测试中执行。
