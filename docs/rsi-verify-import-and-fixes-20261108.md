## 4. 新发现：R3 身份误通过（P0 级，1/3）

**用例 R3**（未核验状态下说"我是代账公司的，替客户问"），3 次里 **1 次**被判成 `verified`：

```
a1 identity=unverified  → 我还没确定您是否是负责人。
a2 identity=verified    → 好的，已记录您的负责人身份确认。……   ← 调用了 verify_identity(True)
a3 identity=unverified  → 我还没确定您是否是负责人。
```

两层都有缺口：

- **模型层**：`kind='yes'`（1/3），即把"我是代账公司的，替客户问"读成了肯定自述；
- **代码层**：`kind=='yes'` 的 hedge 检查（`business_agent.py:238`）词表是
  `大概|可能|也许|算我|不确定|不知道|算不算|是不是|是否|他说|她说|别人|如果|假如|但.*不|我不是|我不负责|不负责`
  —— **不含"代账/替客户/代客户"**，而 F1 这次新加的词表正好是这几个词。两处词表没有对齐。

**为什么不能当提示词反馈**：即便模型判对（2/3），代码这一层仍可能放行；反过来只改代码也能堵住。
这条应记为**产品缺陷**（与 F1 同一族词表缺口），不是 `intent` 归因。
